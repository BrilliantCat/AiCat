# 🐾 AiCat — Локальный автономный ИИ-агент для iPhone 15 Pro (iOS 17.5.1)

> **AiCat** — это персональный офлайн ИИ-ассистент с характером умного, слегка ироничного 3D-кота в черных очках. Он живет прямо в процессоре A17 Pro твоего iPhone, общается через Dynamic Island и мгновенно слушает команды по тройному постукиванию по задней крышке телефона.

## 🚀 Ключевые фичи

1. **Жизнь в Dynamic Island (Live Activity):**
   * Кот отображается в островке в свернутом виде (глаза, эмоции, статус).
   * Команда **«Повисни на лапках»** — кот свешивается с Dynamic Island и держится лапками!
   * Команды **«Помойся»**, **«Кувырок»**, **«Поиграй»**, **«Оденься»** — мгновенные визуальные реакции и колкие шутливые ответы.
   * При тапе на островок открывается развернутое меню и диалог.

2. **Тройное касание крышки (Back Tap):**
   * Вместо занятой кнопки питания настроен мгновенный запуск: постучи трижды по задней крышке iPhone 15 Pro — кот просыпается и слушает речь.

3. **100% Офлайн и приватность (A17 Pro):**
   * **Мозг (LLM):** `Qwen 2.5 3B Instruct` (4-битный квант GGUF с поддержкой Metal).
   * **Слух (STT):** Локальный `Whisper` (мгновенно переводит голос в текст).
   * **Голос (TTS):** Офлайн синтез речи с тумблером Вкл/Выкл в шапке.
   * Ни одного байта твоих данных не отправляется в интернет.

4. **Интерактивный 3D-котик (SceneKit/Metal):**
   * Кота можно погладить пальцем (с тактильным откликом Taptic Engine).
   * Смена гардероба (черные очки, худи, аксессуары).

5. **Системные инструменты (Tool Calling):**
   * Чтение и создание событий в **Календаре**.
   * Запись и проверка **Напоминаний**.
   * Локальные **Заметки и дневник**.
   * Офлайн **RAG** — ответы по загруженным в телефон документам.

## 📱 Как настроить Тройной Стук (Back Tap) на iPhone 15 Pro

1. Зайди в **Настройки** iPhone.
2. Перейди в раздел **Универсальный доступ** -> **Касание**.
3. Прокрути в самый низ и выбери **Касание задней панели**.
4. Нажми **Тройное касание** и выбери команду **AiCat: Голос**.
5. Готово! Теперь из любого экрана три стука пальцем по спинке телефона мгновенно активируют кота.

## 🛠️ Сборка и установка на iPhone без Mac

Так как у тебя Windows-компьютер:
1. Запушь проект в свой GitHub репозиторий.
2. Вкладка **Actions** на GitHub автоматически запустит облачный Mac (`macos-14`), скомпилирует проект и выдаст файл `AiCat.ipa`.
3. Скачай `AiCat.ipa` на компьютер.
4. Установи бесплатную утилиту **Sideloadly** (или **AltStore**) для Windows.
5. Подключи iPhone 15 Pro по кабелю к ПК, укажи свой бесплатный Apple ID и перетащи `AiCat.ipa` в Sideloadly.
6. Приложение установится на твой телефон без единого цента за аккаунт разработчика!
