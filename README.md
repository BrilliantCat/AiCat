# 🐾 AiCat — Локальный автономный ИИ-агент для iPhone 15 Pro (iOS 17.5.1)

> **AiCat** — это персональный офлайн ИИ-ассистент с характером умного, слегка ироничного 3D-кота в черных очках. Он живет прямо в процессоре A17 Pro твоего iPhone, общается через Dynamic Island и мгновенно слушает команды по тройному постукиванию по задней крышке телефона.

## 🚀 Ключевые фичи

1. **Жизнь в Dynamic Island (Live Activity):**
   * Кот отображается в островке в свернутом виде (глаза, эмоции, статус).
   * Команда **«Повисни на лапках»** — кот свешивается с Dynamic Island и держится лапками!
   * Команды **«Помойся»**, **«Кувырок»**, **«Поиграй»**, **«Оденься»** — мгновенные визуальные реакции и колкие шутливые ответы.
   * При тапе на островок открывается развернутое меню и диалог.

2. **Тройное касание крышки (Back Tap):**
   * Вместо занятой кнопки питания настроен мгновенный запуск: постучи трижды по задней крышке iPhone 15 Pro — кот просыпается и слушает речь.

3. **100% Офлайн и приватность (A17 Pro):**
   * **Мозг (LLM):** `Qwen 2.5 3B Instruct` (4-битный квант GGUF с поддержкой Metal).
   * **Слух (STT):** Локальный `Whisper` (мгновенно переводит голос в текст).
   * **Голос (TTS):** Офлайн синтез речи с тумблером Вкл/Выкл в шапке.
   * Ни одного байта твоих данных не отправляется в интернет.

4. **Интерактивный 3D-котик (SceneKit/Metal):**
   * Кота можно погладить пальцем (с тактильным откликом Taptic Engine).
   * Смена гардероба (черные очки, худи, аксессуары).

5. **Системные инструменты (Tool Calling):**
   * Чтение и создание событий в **Календаре**.
   * Запись и проверка **Напоминаний**.
   * Локальные **Заметки и дневник**.
   * Офлайн **RAG** — ответы по загруженным в телефон документам.

## 📱 Как настроить Тройной Стук (Back Tap) на iPhone 15 Pro

1. Зайди в **Настройки** iPhone.
2. Перейди в раздел **Универсальный доступ** -> **Касание**.
3. Прокрути в самый низ и выбери **Касание задней панели**.
4. Нажми **Тройное касание** и выбери команду **AiCat: Голос**.
5. Готово! Теперь из любого экрана три стука пальцем по спинке телефона мгновенно активируют кота.

## 🛠️ Сборка и установка на iPhone без Mac

Так как у тебя Windows-компьютер:
1. Запушь проект в свой GitHub репозиторий (`git push origin main`).
2. Вкладка **Actions** на GitHub автоматически запустит облачный Mac (`macos-latest`), скомпилирует проект (включая виджет и Dynamic Island) и выдаст готовый артефакт `AiCat.ipa`.
3. Скачай `AiCat-iOS` из Actions и распакуй `AiCat.ipa`.
4. Установи бесплатную утилиту **iloader** / **SideStore** / **Sideloadly** для Windows.
5. Подключи iPhone 15 Pro, укажи свой Apple ID и подпиши `AiCat.ipa`.

## 🧠 Как добавить нейросети (Qwen LLM и CoreML Stable Diffusion)

Приложение поддерживает два удобных способа загрузки локальных моделей:

### Способ 1: Прямо через приложение «Файлы» на iPhone (Рекомендуемый)
1. Открой стандартное приложение **Файлы** на iPhone.
2. Перейди в раздел **На моем iPhone** -> **AiCat**.
3. Ты увидишь автоматически созданную папку **Models**.
4. Положи туда:
   - Файл языковой модели: `qwen2.5-3b-instruct-q4_k_m.gguf`
   - Папку CoreML диффузии: `coreml-stable-diffusion-v1-5_split_einsum_compiled` (внутри лежат `TextEncoder.mlmodelc`, `UnetChunk1.mlmodelc`, `UnetChunk2.mlmodelc`, `VAEDecoder.mlmodelc`)
5. Перезапусти AiCat — индикатор процессора в шапке загорится зеленым, а модели мгновенно активируются!

### Способ 2: Вшить внутрь IPA перед установкой на Windows
1. Переименуй `AiCat.ipa` в `AiCat.zip` и открой его.
2. Внутри перейди в папку `Payload/AiCat.app/`.
3. Создай папку `Models` (если её нет) и скопируй туда `qwen2.5-3b-instruct-q4_k_m.gguf` и папку `coreml-stable-diffusion-v1-5_split_einsum_compiled`.
4. Переименуй архив обратно в `AiCat.ipa` и установи через iloader / Sideloadly.



## Доработка офлайн-моделей и питомца

Проект собирается через `project.yml`. GitHub Actions скачивает закреплённый
`llama.cpp b5046`, подключает `StableDiffusion 1.1.1`, выполняет компиляцию,
запускает XCTest на симуляторе и упаковывает IPA. Для локального Xcode сначала
нужен `Frameworks/llama.xcframework` из того же официального архива.

В IPA модели размещаются внутри `Payload/AiCat.app/Models/` до подписи SideStore.
Альтернативный путь на телефоне — «Файлы → На моём iPhone → AiCat → Models».
Файл диалога — `qwen2.5-3b-instruct-q4_k_m.gguf`.
Для изображений нужна папка `coreml-stable-diffusion-v1-5_split_einsum_compiled`
или `sd_coreml`, содержащая `TextEncoder.mlmodelc`, `VAEDecoder.mlmodelc`,
`Unet.mlmodelc` либо обе части `UnetChunk1.mlmodelc` и `UnetChunk2.mlmodelc`,
а также `vocab.json` и `merges.txt`. Изменение фото по описанию дополнительно
требует `VAEEncoder.mlmodelc`. Обнаружение файлов отображается отдельно от
фактического запуска, который происходит при запросе. Обе модели выполняются
последовательно и освобождаются после задачи.

Графика берётся из `AiCat-Visuals`, а анимации приложения из `AiCat-Animation`.
Обе папки нужно включить в Git-коммит. Виджет получает снимок питомца через
App Group `group.com.brilliantcat.aicat` и формирует суточное расписание сцен.
Подпись приложения и расширения должна сохранять доступ к общей группе.
Проверка этого доступа после переподписи SideStore пока требуется на устройстве.
Dynamic Island меняет картинку при обновлении Live Activity и открывает чат
по `aicat://chat`. Частоту фоновых обновлений и срок жизни Live Activity
определяет iOS. Непрерывная APNG-анимация реализована внутри приложения.

В «Фото и аудио» доступны камера, категории объектов через Vision, OCR,
улучшение фото, удаление фона, генерация и изменение изображений через Core ML,
экспорт речи в CAF, синтез короткого музыкального рисунка и обрезка аудио в M4A.
Категории Vision не дают подробного понимания сцены. Для такого диалога
потребуется отдельная мультимодальная модель. Произвольное создание музыки
по тексту также требует дополнительной модели. Для Stable Diffusion 1.5
предпочтительны описания по-английски.

Русский мужской голос выбирается из установленных голосов iOS. Если такого
голоса нет, применяется доступный русский голос. Распознавание речи требует
доступной на устройстве офлайн-модели русского языка.

Локально на Windows проверены синтаксический разбор Swift и чтение YAML.
Компиляция Xcode, XCTest, память и скорость моделей, звук и установка через
SideStore требуют проверки на macOS и iPhone. Полный доступ к данным и
управлению сторонними приложениями зависит от предоставляемых ими API.


### Самостоятельная жизнь, занятия и телефон

Кот восстанавливает энергию во сне, засыпает при усталости и ночью,
чередует отдых, игру, умывание и работу. При голоде ждёт кормления,
при недостатке внимания просит ласку. Игра расходует энергию и повышает
настроение. Закрытое приложение пересчитывает состояние по времени,
виджет использует тот же расчёт. В активном приложении состояние обновляется
раз в минуту. Обновления в фоне и срок жизни Dynamic Island регулируются iOS.

На панели действий появились дыхание, разминка, планка, игра и экран телефона.
Занятия имеют паузу, продолжение и переход к следующему этапу. Прогресс
занятия сохраняется для продолжения после перезапуска. При уходе в фон
занятия и подсчёт повторений ставятся на паузу. Счётчики отжиманий и приседаний
опираются на датчики приближения/ускорения, доступны ручной +1 и изменение
цели через параметр `reps`. Оценка техники движений по камере пока отсутствует.

Команды чата, работающие также без Qwen:
- «дыхание», «разминка», «планка»;
- «пауза», «продолжить занятие», «следующая поза», «стоп занятие»;
- «продолжить тренировку», «стоп тренировка», «засчитай повтор»;
- «заряд батареи», «яркость 40», «таймер 5 минут», «отмени таймер»;
- «найди на карте Казанский собор», «открой сайт https://example.com»;
- «скопируй нужный текст», «запусти команду Мой сценарий».

Таймер использует локальное уведомление и требует разрешения уведомлений.
Запуск команды iOS передаёт запрос установленному сценарию по его точному
имени. Результат действий сценария AiCat автоматически не получает.
Кнопка настроек открывает настройки самого AiCat.
